# Contributing

Thanks for taking the time.

## Before you open a PR

**Most of this repo is generated** from the AdSwipeFile source and is
overwritten on every sync: the manifests, `.mcp.json`, `mcp.json`, `skills/`,
`assets/`, `README.md` and `LICENSE`. A PR against those will be lost.

If one of them is wrong, open an issue saying which file and what is wrong with
it, and it gets fixed at the source.

## What is most useful

- **A skill that leads the assistant astray.** An ad described without its
  link, an ad called a winner or top performer on no data, copy reused word
  for word in "original" hooks, a question it should have refused. Include
  the prompt.
- **A tool that disagrees with the site.** If an ad, brand, niche or format
  differs from its page on adswipefile.com, say which page and what differs.
- **Install trouble.** Which client, which version, and the error.

Do not include sign-in links, codes or tokens.

## Security

Do not open an issue. See [SECURITY.md](./SECURITY.md).
